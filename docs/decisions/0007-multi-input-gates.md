# ADR 0007: многовходовые вентили

**Статус:** принято

* У `AND`, `NAND`, `OR`, `NOR`, `XOR`, `XNOR` число входов задаётся полем компонента
  `inputs` — целое 2…8. Входы называются `A`…`H`, выход — `OUT`. У `NOT` и `BUFFER`
  вход всегда один.
* Значение 2 не записывается: в файле поле отсутствует, поэтому старые проекты открываются
  без изменений, а `schemaVersion` остаётся 1. Поле у других типов — ошибка `SCHEMA_ERROR`.
* Семантика — та же, что для двух входов (ADR 0003), по всем входам: AND — 0, если есть 0;
  OR — 1, если есть 1; XOR — чётность, любой `X` даёт `X`. Неподключённый вход — `X`
  и предупреждение `UNCONNECTED_INPUT`.
* Геометрия: входы через 10 единиц начиная с y=5, высота корпуса `10·N`, выход посередине.
  Для N=2 раскладка совпадает с прежней (40×20). Тело вентиля растягивается до высоты 40;
  при большем числе входов задняя кромка продлевается вертикальной линией, к которой
  подходят входы (обозначение ANSI для многовходовых вентилей).
* Изменение числа входов — правка проекта (`setComponentProps`, undo/redo; в MCP —
  `set_gate_inputs`, а также параметр `inputs` у `add_component`). Уменьшение запрещено
  (`INVALID_CONNECTION`, список занятых выводов в `details.pins`), пока к убираемым
  выводам подключены провода: молча удалять соединения пользователя нельзя.
