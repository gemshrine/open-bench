# ADR 0004: формат файла проекта

**Статус:** принято

* Файл `*.openbench.json`, UTF-8, JSON с отступом 2 и стабильным порядком ключей
  (`serializeCircuit`). Повторное сохранение без изменений даёт тот же текст.
* `schemaVersion: 1`. Файл другой версии отклоняется с понятной ошибкой.
* Схема описана на Zod (`packages/core/src/schema.ts`). JSON Schema
  `docs/project.schema.json` генерируется из неё командой `npm run examples`.
* После проверки структуры проверяются ссылки: уникальность ID, существование
  компонентов, выводов и узлов, не больше одного Word Generator и одного Logic Analyzer.
  Ошибки возвращаются списком (`SCHEMA_ERROR`), UI их показывает и не падает.
* Запись атомарная: временный файл в той же папке, `fsync`, `rename`.
* Ручные значения INPUT сохраняются в файле (`value`), история анализатора — нет.
* Совместимость с `.ewb` и форматами Multisim не заявляется.

Описание полей — [docs/project-format.md](../project-format.md).
