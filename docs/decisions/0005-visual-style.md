# ADR 0005: визуальный стиль

**Статус:** принято

## Контекст

Методички лабораторных работ иллюстрированы снимками классического учебного
схемотехнического редактора 1990-х: белый лист, тонкие чёрные ортогональные провода,
жирные точки соединений, символы вентилей ANSI, синие подписи переключателей `[1]`,
пробники-кружки, серые корпуса генератора слов и логического анализатора. Студенты
должны узнавать на экране то же, что видят в методичке.

## Решение

* Сохраняются компоновка, пропорции, цвета и набор органов управления этого стиля. Все
  символы и окна **нарисованы заново** (SVG/CSS в `apps/desktop/src/canvas/symbols.tsx`,
  `styles.css`). Чужие изображения, иконки, шрифты и код не используются, торговое
  оформление не копируется.
* Выделение — красным цветом (символ, корпус прибора).
* Переключатель — SPDT с двумя контактами (верхний = 1, нижний = 0). Подпись и клавиша
  `[k]` — синим над символом.
* Пробник — кружок: белый (0), красный (1), серый со знаком «?» (X), жёлтый со знаком
  «!» (E).
* Состояние сетей по умолчанию не окрашивается, чтобы схема выглядела как в методичке.
  Флажок **«Уровни»** включает цвет и подписи `0/1/X/E` у каждой сети: требование «не
  полагаться только на цвет» выполняется подписями. Значения выводов также видны в панели
  свойств и во всплывающих подсказках.
* Элементы окон приборов, которые движок не реализует (внешний запуск, Trigger, Clock,
  Breakpoint, «Data ready»), **не показываются**, чтобы не создавать нерабочих кнопок.
  Мелкие кружки по краю корпусов на схеме — элемент оформления корпуса, а не выводы:
  подключаться к ним нельзя.
